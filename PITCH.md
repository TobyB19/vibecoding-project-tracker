# Team Bish Tracker - Pitch & Demo

## The Problem
When you're building solo in a hackathon, context-switching between your code editor, project boards, and AI chat windows slows you down massively. Most project tools are way too bloated for a single builder.

## The Solution
**Team Bish Tracker** is a lightning-fast, highly accessible React and Tailwind kanban board built specifically for solo AI-assisted development.

## Core Features
- **Mid-Grey Accessibility Theme:** Built with custom Slate 200/100 surfaces to kill eye glare and fully pass WCAG AA contrast standards.
- **AI Context Integration:** Every task has a dedicated briefing box and a one-click copy button to instantly throw code prompts into your clipboard.
- **Deliverable Anchors & Progress Bar:** High-level milestones pinned right above the board with a live completion progress bar.
- **Quick Search:** Instant keyword filtering so your board stays clean when you're flooded with tasks.

## Tech Stack
- React (Vite)
- Tailwind CSS
- HTML5 LocalStorage
